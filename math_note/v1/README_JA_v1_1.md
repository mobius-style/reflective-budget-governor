# RHL/RBG 数学パイロット — 結果概要 v1.1(ブラッシュアップ版)

2026-09-19。v1.0(README_JA.md / NOTE.md)と数学・証拠は同一。設計上の発見を前面に出し、
窓長に関する系を1つ追加(機械検査つき)。公開・投稿・稼働コード変更は行っていない。

## 発見1: 「飽和閾値0.70」は、配備中の窓では閾値として機能していない

両検知器は窓内の**観測された**カテゴリ数で正規化したエントロピーから `S = 1 − H/log k` を
計算し、`S ≥ 0.70` で発火する。**窓長18以下では、この条件は「全件一致」と同値**である。

- RBG(窓3): 飽和 = 直近3回の変更種別が完全一致(rewriteは別規則で除外)
- 秘書RHL(窓≤8・5件以上): 飽和 = 直近の提案の価値軸が全部同じ

RBGでは (0.0817, 1]、RHLでは (0.4564, 1] の範囲で閾値をどう動かしても判定は同一。
0.70→0.90は無効。スコアをBoolean「全一致」に置換して1,000系列を再走しても
停止位置・理由の不一致はゼロ。非一致窓が0.70を超えうる最小窓長は19(18:1)。

## 発見2: 集合trigramは逐語反復を見られず、その盲目は定量化できる

長さ3以上の語を何回繰り返しても、増えるtrigramは境界の最大2種類。元の語の異なるtrigramが
**49種類以上**なら、何倍に反復しても類似度は0.98以上(B腕の停止閾値)。32以上でRBGは
`no_change`枝に入り、27以上で d̂_R は平衡ε(0.05)を下回る。RBGは長さより先に類似度を判定する
ため、毎回長さが倍増する列と全く変化しない列が**バイト単位で同一のトレース**を生む
(実行済み証人あり)。論文のhr_027(≈50回反復、類似度0.996)はまさにこの領域。

## 発見3: 停止性については新規定理なし

整礎降下と局所ガードの反例はT1に既存。稼働中のM guardは「未封印世代を重ねて開かない」
直列化であり、意味ポテンシャルの厳密減少は実装していない。候補命題は撤回。

## 含意

1. **RBG論文(DOI 22031367)§2/§5**: 「saturation ≥ 0.70」は「同種の非rewrite変化が3連続」と
   読むべき。アブレーションの「saturationが節約と品質コスト両方の主因」に機構的説明がつく
   (最も早く発火する信号だから)。companionリポジトリへの補足は妥当。Zenodo v1.1を切るかは
   オーナー判断(数値は一切変わらない)。
2. **秘書RHL**: 既定設定では軸の全一致でしか発火しない極めて保守的な検知器。現在の
   `sat≈0.19` は「19%飽和」ではなく「非一致窓」の意味。0.70の調整は無効で、窓長・正規化の
   変更は設計変更として審査すべき。
3. **反復盲目への最小修正**: 不可能性の結果により、集合同値類の内部で変化する特徴
   (正規化長・出現回数・反復比 len/dedup-len)が**必要**。十分性・自然文での有効性は未測定。
4. **次の研究**: 第4信号を事前登録の偽陽性基準つきで凍結し、held-out系列で評価する。

未解決2件はCLOSED / **v1.1で第二セッション(Claude)が命題を手計算で再導出し、検収を

## 位置づけ

集合shingleの多重度喪失(Broder 1997)、エントロピー集中(Sason 2018)、観測サポート正規化は
既知。本ノート固有なのは、これらが**この実装**にもたらす厳密な帰結(全一致同値と窓長範囲、
閾値27/32/49、全方策衝突族、全コーパス再走)。再現可能な技術ノートとしてGO、新規性主導の
数学論文としてはNO-GO。
