## 今回できたこと

「窓長18までは全一致」という有限範囲の結果を、**任意の窓長・任意の閾値について使える一般定理**に発展させました。

長さ n の窓で、出現回数は正の整数、種類数 k は実際に出現した種類だけとします。飽和スコア S=1−H/log k が、全一致でない窓で最も大きくなるのは、必ず **二種類が n−1 対 1** のときです。最大値は

\[
M(n)=1-\frac{h(1/n)}{\log 2},\qquad
h(p)=-p\log p-(1-p)\log(1-p).
\]

この上限は達成され、等号の成立条件も特定できています。したがって閾値 τ に対して、混在でも発火できる最小窓長 n*(τ) が一意に決まります。

| 閾値 τ | 混在で発火し始める最小窓長 n* | 最初の混在例 |
|---:|---:|---:|
| 0.10 | 4 | 3:1 |
| 0.25 | 5 | 4:1 |
| 0.50 | 10 | 9:1 |
| 0.70 | **19** | 18:1 |
| 0.80 | 33 | 32:1 |
| 0.90 | **78** | 77:1 |
| 0.95 | 179 | 178:1 |
| 0.98 | 524 | 523:1 |
| 0.99 | 1,163 | 1,162:1 |

各境界は整数演算で確定しました。例えば0.90の場合、窓77の最大値は約0.899999057で、0.90に極めて近くても発火しません。近似計算だけで境界を決めない価値がある例です。

「窓長 n* 以上なら混在の**中に**発火するものが存在する」という結果であり、すべての混在が発火するという意味ではありません。判定は S≥τ。S>τ では境界の扱いが異なります。

## 数学的価値の位置づけ

本版で増えた価値は、特定の0.70・窓18という設定を越えて、**設計前に、閾値と窓長の組合せが何を判定するか決められること**です。証明、等号条件、逆関数による設計式、厳密な計算器を一つにまとめています。閾値を1へ近づけると必要窓長がどう発散するかも導出しました。

ただし、固定した種類数での最小エントロピーの式は [Beisel・Moreteau（1997）の原論文](https://www.jnbeisel.net/uploads/5/4/4/2/54425847/ecomod_1997_beisel_%26_moreteau_shannon_index.pdf) に既出です。今回の種類数をまたぐ一般化についても、文献全体に対する初出性は確定していません。**一般性と再利用性は増しましたが、新規性の優先権は主張しません。** 詳細は [LITERATURE.md](LITERATURE.md)。

## クロード版から補正した解釈

- **閾値調整が無効なのは一定の区間内。** 窓8では約0.456435557を超える閾値がすべて全一致判定になります。これより下げれば混在を許せるため、「窓を19以上へ変える以外に調整不能」ではありません。連続スコアそのものと発火の真偽も別です。
- **飽和が最も早い信号、とは言えない。** ソース上、飽和は最短3回、平衡とループは最短2回です。実行可能な反例を保存しました。数式だけから節約・品質低下の因果説明は導きません。
- **hr_027 は直前文字列の厳密な反復ではない。** 再計算すると既存trigram589種に対して追加5種、削除0種でした。「純粋な反復なら追加は最大2種」の定理を直接適用できません。一般の集合包含の式により、実測cosine≈0.995782352・d̂_R≈0.005897592を再現できます。
- **必要なのは区別できる観測情報。** それを既存信号へ組み込むこともでき、必ず第4信号という構成を要求する定理ではありません。
